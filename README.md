# 人工呼吸器シミュレーター

研修医など学習者向けの、人工呼吸管理を学ぶための**教育用シミュレーター**です。
実在の医療機器ではありません。実際の診療判断・投薬・機器設定には使用できません。

モードの切り替え、初期設定、血液ガス評価と設定変更、weaning（SBT と抜管）までを
ひと続きの流れとして学べることを目指しています。

## 学習コース

呼吸器を触ったことがない人が 1 から学べるよう、**6 章 19 レッスン**の学習コースを
用意しています。レッスンはモーダルで画面を塞がず、機器の画面の下に細い帯として出るので、
解説を読みながら実機そのものを操作して進められます。

| 章 | 内容 |
| --- | --- |
| 第1章 機械を読む | 波形と計測値、PIP と Pplat、コンプライアンスと気道抵抗 |
| 第2章 挿管直後の初期設定 | 予測体重と一回換気量、呼吸回数と分時換気量、PEEP と FiO₂ |
| 第3章 モードの違い | 量規定と圧規定、トリガとミストリガ、SIMV と PSV |
| 第4章 血液ガスを読む | 4 ステップの読み方、CO₂ と換気量、P/F 比と PEEP、permissive hypercapnia |
| 第5章 アラームとトラブル | 気道内圧上昇の切り分け、auto-PEEP、DOPE |
| 第6章 離脱と抜管 | 離脱条件、SBT と RSBI、抜管と抜管後 |

課題の進み方は 3 種類だけです。

- **操作**：設定キーやハードキーを実際に押す（例：吸気ポーズを押して Pplat を測る）
- **状態**：画面の値が目標に入り、一定時間それを保つ（例：MV を 6.0〜8.5 L/分 に 30 秒）
- **クイズ**：選択肢に答える。正解するまで進まず、正解すると解説が出る

レッスンによっては、課題に入った瞬間に病態が起こります（第5章の痰づまりなど）。
目標値が本当に到達できるかは、`web/test.js` と `Tests/VentilatorCoreTests/LessonTests.swift`
の両方でシミュレーションを回して検証しています。

## 構成

| 場所 | 内容 |
| --- | --- |
| `web/` | 動作確認用のプロトタイプ（JavaScript）。物理エンジンと UI の検証に使う |
| `web/lessons.js` | 学習コースの中身と進行ロジック |
| `swift/VentilatorSim/` | iPhone アプリ本体（Swift Package + SwiftUI） |
| `swift/.../Sources/VentilatorCore/Lessons*.swift` | 学習コースの Swift 版（内容は `lessons.js` と同一） |

`web/` は Swift 版を書く前に挙動と数値を固めるための場所です。
`engine.js` と `Sources/VentilatorCore/VentilatorEngine.swift` は同じ式・同じ定数で、
どちらにも同じ内容のテストがあります。

## 呼吸生理モデル

単一コンパートメント肺（コンプライアンス C と気道抵抗 R）を 1 つだけ持ち、
換気モードはその上に載る制御則として書いています。モードごとに別の挙動を
書き分けてはいません。こうすると auto-PEEP・非同調・浅速呼吸が、
特別に作り込まなくても設定の結果として現れます。

運動方程式

```
Paw + Pmus = V/C + R·V̇
```

を時定数 τ = R·C の指数積分で解くため、刻み幅を変えても結果が変わりません
（60 倍速でも 1 倍速と同じ値になることをテストで確認しています）。

ガス交換はシャント式と Severinghaus の酸素解離曲線、酸塩基は
Henderson-Hasselbalch、腎性代償は時定数 90 分で近似しています。
血液ガスは採血から 2 分後に返るので、設定を当て推量で連打しても進みません。

## 動かす

```sh
cd web
node test.js        # 呼吸生理エンジンの数値テスト
```

UI は `web/index.html` をブラウザで開きます（`file://` で動きます）。
配布用の 1 ファイル版は次で作ります。

```sh
node web/build.js        # web/preview.html を生成する
```

```sh
npm install playwright   # 画面の通し確認をする場合
node web/smoke.js
```

ブラウザの中で iPhone の枠に入れて確かめるには `web/iphone.html` を開きます。
実機と同じ論理ピクセル（iPhone 13 mini / 16 / 16 Pro Max）で、ステータスバーと
ホームバーの分を差し引いた範囲にアプリを置くので、実機の見え方とずれません。

## iPhone アプリを動かす

macOS と Xcode 16 以降が要ります。

```sh
git clone https://github.com/mynrminto/respirator_game
open respirator_game/swift/VentilatorSim.xcodeproj
```

Xcode が開いたら、上の実行先を iPhone のシミュレータにして ⌘R です。
スキーム **VentaSim** は用意済みなので、選び直す必要はありません。

`swift/VentilatorSim/App/` が画面、`swift/VentilatorSim/`（Package.swift）が
ローカルパッケージ `VentilatorCore` として繋がっています。呼吸生理エンジンだけを
試すなら Xcode なしでも動きます。

```sh
cd swift/VentilatorSim
swift test
```

## 画面

実機の人工呼吸器と同じ構成にしています。ページはスクロールしません。

- 上段：機種名・患者・アラーム帯・消音・時刻
- 画面：気道内圧／流量／容量の 3 波形（左から右への連続スイープ）と計測値
- 画面切替：波形／ループ（P–V、F–V）／トレンド
- モードキー：VC-AC / PC-AC / SIMV / PSV / CPAP
- 設定キー＋ダイヤル：キーを選び、ダイヤルを回し、「確定」で反映（実機と同じ確定操作）
- ハードキー：吸気ポーズ、呼気ポーズ、100% O₂、気管吸引、波形停止
- 学習コース中は、画面の下にレッスンの帯（課題・ヒント・クイズ・進捗）が出ます

早送り（× 1 / × 10 / × 60）と症例選択、血液ガス、離脱はシミュレーター側の機能で、
機器のキーとは色を分けています。

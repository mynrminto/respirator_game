# 人工呼吸器シミュレーター

研修医など学習者向けの、人工呼吸管理を学ぶための**教育用シミュレーター**です。
実在の医療機器ではありません。実際の診療判断・投薬・機器設定には使用できません。

モードの切り替え、初期設定、血液ガス評価と設定変更、weaning（SBT と抜管）までを
ひと続きの流れとして学べることを目指しています。

## 構成

| 場所 | 内容 |
| --- | --- |
| `web/` | 動作確認用のプロトタイプ（JavaScript）。物理エンジンと UI の検証に使う |
| `swift/VentilatorSim/` | iPhone アプリ本体（Swift Package + SwiftUI） |

`web/` は Swift 版を書く前に挙動と数値を固めるための場所です。
`engine.js` と `Sources/VentilatorCore/VentilatorEngine.swift` は同じ式・同じ定数で、
どちらにも同じ内容のテストがあります。

## 呼吸生理モデル

単一コンパートメント肺（コンプライアンス C と気道抵抗 R）を 1 つだけ持ち、
換気モードはその上に載る制御則として書いています。モードごとに別の挙動を
書き分けてはいません。こうすると auto-PEEP・非同調・浅速呼吸が、
特別に作り込まなくても設定の結果として現れます。

運動方程式

```
Paw + Pmus = V/C + R·V̇
```

を時定数 τ = R·C の指数積分で解くため、刻み幅を変えても結果が変わりません
（60 倍速でも 1 倍速と同じ値になることをテストで確認しています）。

ガス交換はシャント式と Severinghaus の酸素解離曲線、酸塩基は
Henderson-Hasselbalch、腎性代償は時定数 90 分で近似しています。
血液ガスは採血から 2 分後に返るので、設定を当て推量で連打しても進みません。

## 動かす

```sh
cd web
node test.js        # 呼吸生理エンジンの数値テスト
```

UI は `web/index.html` をブラウザで開きます（`file://` で動きます）。

```sh
cd web
npm install playwright   # 画面の通し確認をする場合
node smoke.js
```

Swift 側は Xcode で `swift/VentilatorSim/Package.swift` を開くか、

```sh
cd swift/VentilatorSim
swift test
```

## 画面

実機の人工呼吸器と同じ構成にしています。ページはスクロールしません。

- 上段：機種名・患者・アラーム帯・消音・時刻
- 画面：気道内圧／流量／容量の 3 波形（左から右への連続スイープ）と計測値
- 画面切替：波形／ループ（P–V、F–V）／トレンド
- モードキー：VC-AC / PC-AC / SIMV / PSV / CPAP
- 設定キー＋ダイヤル：キーを選び、ダイヤルを回し、「確定」で反映（実機と同じ確定操作）
- ハードキー：吸気ポーズ、呼気ポーズ、100% O₂、気管吸引、波形停止

早送り（× 1 / × 10 / × 60）と症例選択、血液ガス、離脱はシミュレーター側の機能で、
機器のキーとは色を分けています。
